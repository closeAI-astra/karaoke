# ピッチ採点ステージ

歌の音声・動画を読み込むと、音程をカラオケのように流して表示し、最後に点数をつけるアプリです。
GitHub Pages で公開すると、このリポジトリの `media/` フォルダに置いた音声・動画が「曲ライブラリ」に自動で並びます。

ファイルの解析はすべて見ている人のブラウザの中で行われ、どこにも送信されません。

## フォルダ構成

```
index.html                 アプリ本体（1ファイル）
media/                     ここに曲を置く
  sample-melody.wav        サンプル（合成音声。わざと4か所ずらしてある）
  sample-melody.ref.wav    サンプルのお手本
  index.json               曲名の表示用（なくても動く）
.nojekyll                  GitHub Pages にファイルをそのまま配信させるための空ファイル
```

## 公開手順

1. GitHub で **Public** のリポジトリを作る（例：`pitch-stage`）。
2. このフォルダの中身をすべてリポジトリに置く（`git push` するか、ブラウザの「Add file → Upload files」）。
3. リポジトリの **Settings → Pages** を開き、Source を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存する。
4. 数分後に `https://ユーザー名.github.io/リポジトリ名/` で開けるようになる。

## 曲を追加する

- `media/` に音声（mp3・m4a・wav・ogg・flac など）か動画（mp4・webm・mov）を置くだけで、次に開いたときに一覧に出ます。
- **お手本と組にする**：`曲名.ref.拡張子` という名前で置くと自動で組になります。
  例：`kaeru.mp4`（自分の歌）と `kaeru.ref.mp3`（お手本）
- **曲名を日本語で表示したい**ときは `media/index.json` に書きます。

```json
[
  { "file": "kaeru.mp4", "title": "かえるの歌（2回目の録音）" },
  { "file": "take3.m4a", "title": "練習テイク3", "ref": "guide.mp3" }
]
```

`ref` を書けば、名前のルールに関係なくお手本を指定できます。

## ファイルサイズについて

GitHub の公式ドキュメントでは、ブラウザからアップロードできるのは1ファイル25MiBまで、`git push` では100MiBを超えるファイルは拒否されます。
このアプリは Git LFS で管理されたファイルには対応していません。長い動画は音声だけ（m4a や mp3）に書き出して置くのがおすすめです。

## 便利なURL

| URL の付け足し | 意味 |
|---|---|
| `?song=kaeru.mp4` | 開いた瞬間にその曲を読み込む（曲を選ぶと自動でアドレスに付きます。共有用） |
| `?repo=ユーザー名/リポジトリ名` | 別の公開リポジトリの曲一覧を読む |
| `&dir=songs` | `media` 以外のフォルダを読む |
| `&branch=dev` | 既定以外のブランチを読む |

1つのファイルだけ読みたいときは、画面の入力欄に GitHub のファイルURL（`https://github.com/…/blob/main/…` の形でも可）を貼れば読み込めます。

## 注意

- 一覧の取得には GitHub API を使います。ログインなしの利用回数には上限（1時間あたり60回）があり、超えると一時的に一覧が出なくなります。そのときは `media/index.json` に曲を書いておくと、そちらから一覧を作ります。
- 非公開（Private）リポジトリの曲は読めません。
- 動画はアプリと同じリポジトリに置くのが確実です。別リポジトリやURL指定の動画は、ブラウザによっては映像が表示されないことがあります（その場合も音声で採点します）。
- 伴奏入りの音源では楽器の音も拾います。ボーカルだけの録音がいちばん正確です。
